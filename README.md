# FC Power Showcase

A fan-made football power showcase prototype built with React, TypeScript, Vite and Three.js.

## Features

- 3D animated football showcase cards
- OVR values above 99
- OVR-driven animation intensity
- TESTMENU_1.0 power controls
- Selected-player or all-player power changes
- Player database and team screens
- English, Spanish, French, German, Portuguese, Japanese and Korean UI
- Responsive layout

## Run locally

```bash
npm install
npm run dev
```

This project uses original interface code and does not include proprietary FC game assets.
